## Compile operations independently

| Operation | Existing implementation | General implementation task |
|---|---|---|
| FBI colour/alpha arithmetic | MAME-derived CPU oracle and optional generic TEV compiler | Integrate generic compilation with rejection; preserve constants until their final use |
| Chroma/parity | Black predicate and selected original-source parity | Select original OTHER RGB/alpha from decoded fields; carry source lifetime requirements |
| Alpha testing | GX compare for selected paths | Compose all eight comparisons with chroma/parity, without changing survivor alpha |
| Blend/depth interaction | Selected guards and primitive proofs | One semantic rejection policy shared by every equation/texture path |
| TMU arithmetic | Replacement/pass-through | Decode both independent TMU equations and compile within available stages/coordinates |
| Fog | Mode41 approximation | Decode source/add/multiply/constant operations and preserve rejection/blend alpha |
| Sampling | Common formats, fixed mip | Inventory layouts/formats/LOD independently from colour equations |
| Framebuffer/raster | W-depth approximation, basic clipping/clear | Explicit capability decisions for alpha planes, separate depth sources, stipple and quantization |

## Rejection policy

Original OTHER RGB/alpha determine chroma/parity before the FBI equation. Guest alpha testing consumes the resulting equation alpha. Fog then precedes blending and framebuffer writes. Preserve these distinct values in the stage plan.

Choose the rejection encoding from semantics: binary acceptance when original alpha is unobservable; otherwise preserve survivor alpha and gate rejected fragments to zero when the guest alpha test already rejects zero. An additional zero-alpha rejection needs a framebuffer-neutrality proof (appropriate source-alpha blending with no depth writes, or EQUAL writes of identical depth), or a positive-alpha proof. Alpha-zero fragments that can change colour or depth require a separately designed representation/pass. Do not silently discard them.

Preflight the entire pipeline before emitting GX state: stage count including fog/depth, original-source dependencies, scratch-register ownership, texture-coordinate needs and capability reason. Results must distinguish implemented approximation from unsupported behavior; TEV rounding is not MAME pixel equivalence.

## Implemented shared rejection policy

The renderer preserves the guest comparison when adding rejection. Positive-alpha admission is derived from decoded passthrough-alpha equations and vertex bounds, not a framebuffer tuple.

### Single-copy native FIFO storage

The default-off WII_PERF_NATIVE_FIFO_WORDS=1 / WII_LIVE_NATIVE_FIFO_WORDS=1 experiment uses native_fifo_words.h instead of the prior hash-page shadow store. Native values occupy the existing8MiB VRAM allocation; a word bitmap identifies their representation. Scalar overwrites clear representation bits, logical device reads return the same values, and raw texture/scanout observers materialize only their requested byte ranges. Other backends request full materialization before callbacks. Buffer replacement flushes the old owner; device reset clears contents and metadata. Native geometry reads native words into its transient ten-float scratch, with no populated persistent capture_vertices copy. A partially materialized vertex uses logical per-word reads. Presence, versions, packet admission, strip state and scheduling remain intact. This removes byte serialization and the persistent vertex duplicate from this experimental route, but retains the original device contract and encoded commands/materials.

The production default and prior shadow experiment are unchanged.
